# Kanika's Vision

Create the foundation and design system for a premium personal-brand website for Kanika Tekriwala.

IMPORTANT:
This is a personal website for Kanika Tekriwala, NOT a JetSetGo corporate website and NOT a flight-booking website.

Use the uploaded reference image as visual inspiration for the overall visual language. Do not copy its content, branding, person, exact layout or design.

CORE EXPERIENCE:

The website should feel like:

Luxury editorial
+
Founder personal brand
+
Modern aviation

The visual personality should be:
- Bold
- Premium
- Sophisticated
- Confident
- Modern
- Editorial
- Executive
- Minimal but visually rich

COLOUR SYSTEM:

Primary background: #080A0D
Secondary background: #111318
Primary orange: #FF5A1F
Secondary orange: #FF6A2A
Primary text: #F5F5F5
Secondary text: #A7A7A7
Border: #25282D

Use black as the dominant colour.

Use white for primary typography.

Use orange as the signature accent for:
- Highlighted words
- CTA buttons
- Small labels
- Timeline markers
- Key numbers
- Underlines
- Hover states
- Small decorative elements

Do NOT use:
- Gold
- Champagne
- Blue
- Purple
- Green
- Pink
- Additional accent colours

TYPOGRAPHY:

Use a strong modern sans-serif for large headings and a clean readable sans-serif for body text.

Create a strong contrast between:
- Oversized headlines
- Small uppercase labels
- Supporting text

DESIGN LANGUAGE:

Use:
- Oversized typography
- Large photography
- Asymmetric editorial layouts
- Dark panels
- Thin borders
- Orange highlights
- Generous whitespace
- Subtle geometric details
- Smooth premium transitions

Avoid:
- Generic SaaS UI
- Generic portfolio templates
- Excessive rounded cards
- Glassmorphism
- Excessive gradients
- Excessive shadows
- Cartoon illustrations
- Cheap-looking animations

NAVIGATION:

KANIKA

About
Journey
Ventures
Ideas
Speaking
Media

Primary CTA:
Invite Kanika to Speak

RESPONSIVENESS:

Use a mobile-first approach.

Use Tailwind's standard responsive breakpoints.

Desktop layouts can be asymmetric, but mobile layouts must be intentionally redesigned for smaller screens.

TECHNICAL DIRECTION:

Use reusable components.
Keep the codebase modular.
Create a consistent design-token system for colours, typography, spacing and buttons.

Do not add authentication, payments, database functionality or unnecessary backend systems.

Do not invent personal information.

For information that has not yet been provided, use editable placeholders.

At this stage, establish the design system, global styles, navigation structure and basic page architecture.

Do not overbuild the website yet.
