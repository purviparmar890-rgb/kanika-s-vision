# Kanika Tekriwala Personal Brand Foundation

## Goal
Create the first polished foundation for Kanika Tekriwala’s personal website: a dark, editorial, aviation-informed experience that clearly reads as an individual founder brand rather than a corporate or booking site.

## What will be built
- Replace the blank homepage with a restrained first-screen editorial composition using editable copy placeholders where personal facts are missing.
- Add a responsive site header with the KANIKA wordmark, the requested navigation labels, and the “Invite Kanika to Speak” action.
- Establish the core page architecture for About, Journey, Ventures, Ideas, Speaking, and Media, with each destination using a simple consistent placeholder layout rather than invented content.
- Create a reusable visual system for headings, labels, body copy, buttons, borders, spacing, and dark surfaces.
- Add purposeful micro-interactions and a mobile navigation treatment while respecting reduced-motion preferences.
- Add unique page titles and descriptions for every destination.

## Visual direction
- Dominant near-black background with charcoal sections and fine graphite borders.
- Warm orange reserved for emphasis, interaction, and small geometric details.
- Oversized modern typography, uppercase navigation labels, strong whitespace, and asymmetric editorial rhythm.
- No corporate aviation sales language, booking controls, generic feature-card grids, glass effects, decorative gradients, or invented biography claims.

## Technical notes
- Use the existing React and Tailwind foundation with shared components and semantic design tokens.
- Keep all content presentation-only; no login, payments, storage, forms, or backend systems.
- Use CSS-drawn aviation-inspired linework for the initial foundation so no unapproved portrait or personal imagery is introduced.
- Verify the homepage and navigation at desktop and mobile sizes, then confirm the preview reports no build or runtime errors.
